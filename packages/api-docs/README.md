# @4gaboards/api-docs

OpenAPI 3.1 spec of the 4ga Boards API

[`openapi/openapi.yaml`](openapi/openapi.yaml) is the source of truth about API

Edit it by hand when you add or change an endpoint.
Its `info.version` is always `latest`. Stable releases snapshot it as
`openapi/<version>/openapi.yaml`, with `info.version` set to the release version.
It is rendered with Swagger UI on the docs site (`RARgames/4gaBoardsDocs`, served at `/api/`), which
downloads the API spec from this repository at build time.
Nothing from this package ships with the server.

## Keeping the spec in sync

- The `API Docs` workflow runs `check` when routes, controllers or the spec change
- When the API spec changes on `main`, the workflow notifies the docs repository, which rebuilds and deploys
  the docs site
- Operations generated by `bootstrap` carry `x-needs-review: true`; remove it once the request and response
  schemas have been reviewed. The generator only knows the declared `inputs` and `exits` of each controller, so
  response bodies (`item` / `items` / `included`) have to be described by hand
